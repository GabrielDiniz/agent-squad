# Backlog de Implementacao

Backlog executavel por etapas para evolucao do projeto.

## Estrutura

- [Indice de fases](indice-fases.md)
- [Fases ativas](active/phases)
- [To-dos ativos](active/todos)
- [Fases concluidas](done/phases)
- [To-dos concluidos](done/todos)
- [Inbox de novos requisitos](inbox/README.md)
- [Template de nova fase](templates/fase-template.md)

## Como usar

1. Registre novos requisitos no inbox.
2. Converta requisito em fase na pasta active.
3. Execute por PR e atualize o indice de fases.
4. Ao concluir, mova fase e TODO para done.
